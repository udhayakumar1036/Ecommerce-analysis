# E-Commerce Customer & Sales Analytics — Project Summary

This project analyzes e-commerce transaction data to understand sales performance, customer purchasing behavior, product performance, and customer value.

The project began with raw transaction data, which was cleaned and prepared using Python. Exploratory Data Analysis was then performed to identify important sales and customer patterns.

SQL Server was used to perform business-focused analysis, including revenue analysis, product performance, country performance, monthly sales trends, customer purchasing frequency, and average order value.

RFM (Recency, Frequency, Monetary) analysis was used to segment customers into groups such as Champions, Loyal Customers, Potential Customers, At Risk, and Lost Customers.

The analysis identified high-value customers, repeat and one-time customers, top-performing products, strong markets, and important sales trends. These findings were converted into actionable business recommendations focused on customer retention, product inventory, marketing, and revenue growth.

### Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, SQL Server, SQL Server Management Studio, and Power BI.

### Key Result

The project demonstrates an end-to-end data analytics workflow: *data cleaning → exploratory analysis → visualization → RFM segmentation → SQL analysis → business insights → recommendations.
